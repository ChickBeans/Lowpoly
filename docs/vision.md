# Memory Polygon（思い出ポリゴン）：サービスの構想

迷ったらここに戻る。めったに変えない。

## 一言で
**写真に残っている一瞬に、もう一度時間を与える。**

写真は「その瞬間」しか残さない。でも思い出には、その写真の前に時間があった。
Memory Polygon は、写真を**ゴール**に置き、そこへ向かう短い時間をポリゴンの世界で再構成する。
見終わったときに「これが、あの日の写真になるんだ」と感じてもらうのが目的。

- 写真を3D化するサービスではない
- AIで写真を動画にするサービスではない
- ゲームではない

## 基本の体験：Memory Movie（約60秒）
| 時間 | 内容 |
|---|---|
| 0〜40秒 | 写真に至るまでの時間（ユーザーが書いたその日の出来事を、場面にする） |
| 40〜45秒 | 写真を撮るために、写真の位置・向き・ポーズへ集まっていく |
| 45秒 | 写真と同じ構図になり、カシャッ（フラッシュ、シャッター音、オレンジの日付） |
| 45〜60秒 | その瞬間を保持。地名が出て、**本物の写真へ切り替わる**（答え合わせ） |

「収束してシャッター」という型は守る。長さは将来30〜60秒で変えてよい。

## なぜポリゴンなのか
- リアルなAI動画は、顔・手・服が少しずつ変わり、「リアルなのに何か不自然」になる。
- 最初から PS1 / N64 時代のポリゴンにすれば、不自然さは「作品の味」になる。
- 写真の完全コピーではなく、**写真を見たときに蘇るもの**（髪型・服・場所・立ち位置・ポーズ）を残し、それ以外は大胆に省く。

## AIの役割：ディレクター
- AIは写真と文章を読んで「誰が・何を・どの順で・最後はどの構図か」を決める。
- **座標や秒数はAIに決めさせない。** 「45秒ちょうどに写真の位置へ揃う」はプログラム（director）が逆算して保証する。
- AIに毎回3Dモデルをゼロから作らせない。人が品質を管理した部品（体・髪・服・小物・背景・動き）を、AIが選んで組み合わせる。
- AIとプレイヤーの間は、決まった形式のデータ（Scene Definition）でつなぐ。

## キャラの方針
- 「この人だ」と分かることが大事。髪型・髪色・服・眼鏡・体型・小物で本人らしさを出す。
- 人種別のモデルは作らない。**共通の体（2〜3体）＋顔や体型のダイヤル＋髪・服のパーツ**で、見えている特徴から組み立てる。
- ユーザーが「ちょっと直す」UI（髪型・色・服・体型・小物）は用意する。本格的なキャラクタークリエイターにはしない。

## 最初の利用者と広がり
1. カップル（旅行、プロポーズ、記念日）
2. 家族（ハイキング、七五三、入学、結婚式 …）
3. 人生のアルバム（複数のMemoryを順に再生。フォトフレームは遠い将来の話）

## やらないこと
- 写真をそのまま貼る（最後の答え合わせで本人に見せる場合を除く）
- 実在のキャラクターやゲームの絵の再現（有名キャラは一般的な姿に置き換える）
- クエスト・戦闘・スコア・巨大マップ・複雑なNPC
- 何でも入りの壮大な設計を最初から作ること

## 機能を足すときの判断基準
「それは『写真に残っている一瞬に、もう一度時間を与える』体験を強くするか？」
強くしないものは後回し。
