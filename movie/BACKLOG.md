# Memory Movie：改善リスト

見た人の感想から出たもの。上ほど優先。

## 体験
- [x] **撮影後に本物の写真を表示する**（レイキャビクで実装：シャッター→ポリゴンのまま数秒→本物の写真へクロスフェード）：シャッターのあと、本物の写真へ切り替える（答え合わせの瞬間）。
  写真はリポジトリに入れず、本人に渡す動画ファイルを書き出すときだけ合成する。
- [x] **日時の表示**（フィルムカメラ風のオレンジの日付。シーンの `date` に書く。写真からの自動読み取りはまだ）：「2024年5月12日 10:42」のように、地名と一緒に出す。
  - 再生ページで写真を選んだときは、写真の撮影日時（EXIF）から自動で読む
  - チャットで送られた写真は日時が消えていることがあるので、その場合は日時を書いてもらう

## 仕組み
- [ ] **人どうしの重なり防止**：一列で歩く・階段を登るときに前の人と重ならないよう、自動で間隔を空ける（ハイキングの日の階段で発生）。

- [ ] **壁の通り抜け**：ハンバーガー屋の入口で、ドアではなく壁をすり抜けて入っていた。経路が建物の壁を横切らないかチェックする仕組みを入れる。
- [ ] **左右の手の取り違え**：撮影ポーズで、彼女がカップを持つ手が写真と逆だった。最後のポーズは写真の左右と照合する。

## キャラ（作り込みの段階で）
- [ ] **ひざの関節**：脚が1本の棒なので、座ると脚がまっすぐ前に突き出る。太ももとすねを分けて、ひざを曲げられるようにする。
- [ ] **髪のつなぎ目**：彼女の長い髪で、頭と髪のすき間から地肌が見える（はげて見える）。
- [ ] **顔の差をつける**：男性の顔が1種類しかない（ハイキングとレイキャビクで同じ顔）。目・眉・口・輪郭・鼻のパーツを複数用意して差を出す。

- [ ] **本物の写真の画質**：今は640×480の画面に描いてから拡大しているので、本物の写真が粗く見える。写真部分だけ高解像度で合成する。

## 検証の記録
- ロンドンの寺院：彼女に見せて「可愛い」と好評
- ハイキングの日：母に見せる前から「欲しい」との反応。寺院の動画を見て「欲しい」
- レイキャビク、最初の日：本物の写真への切り替えと日付を初めて入れた版。本人の感想は「素晴らしいし、めっちゃかわいい」
