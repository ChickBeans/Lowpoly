# Memory Movie：改善リスト

見た人の感想から出たもの。上ほど優先。

## 体験
- [ ] **撮影後に本物の写真を表示する**：シャッターのあと、本物の写真へ切り替える（答え合わせの瞬間）。
  写真はリポジトリに入れず、本人に渡す動画ファイルを書き出すときだけ合成する。
- [ ] **日時の表示**：「2024年5月12日 10:42」のように、地名と一緒に出す。
  - 再生ページで写真を選んだときは、写真の撮影日時（EXIF）から自動で読む
  - チャットで送られた写真は日時が消えていることがあるので、その場合は日時を書いてもらう

## 仕組み
- [ ] **人どうしの重なり防止**：一列で歩く・階段を登るときに前の人と重ならないよう、自動で間隔を空ける（ハイキングの日の階段で発生）。

## キャラ（作り込みの段階で）
- [ ] **顔の差をつける**：男性どうしの顔が似すぎている。目・眉・口・輪郭・鼻のパーツを複数用意して差を出す。

## 検証の記録
- ロンドンの寺院：彼女に見せて「可愛い」と好評
- ハイキングの日：母に見せる前から「欲しい」との反応。動画を見たあとの反応は確認中
