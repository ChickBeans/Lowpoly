# ローポリ

旅の写真をもとに作った、歩ける思い出のローポリシーン集。

各シーンは1つのHTMLファイルで、Three.js（r128）をCDNから読み込んで動きます。画像や3Dモデルのファイルは使わず、地形・建物・人物の顔まで、すべてコードで描いています。

## シーン

| シーン | 場所 | ファイル |
|---|---|---|
| 薄氷の海岸 | アイスランド | `iceland.html` |
| 芸術科学都市の水の上 | バレンシア | `valencia.html` |
| ヘミスフェリックの瞳の中 | バレンシア | `hemisferic.html` |

## 操作

- 十字キー：歩く（キーボードは WASD）
- A：ジャンプ（スペース）
- B：氷を拾う／投げる（E、アイスランドのみ）
- ドラッグ：視点を回す、ピンチ／ホイール：ズーム
- 表示モード：初代プレステ風／64風／PS2風

## 公開のしかた

GitHub Pages を有効にする（Settings → Pages → Branch: main / root）と、`index.html` がトップページになります。
